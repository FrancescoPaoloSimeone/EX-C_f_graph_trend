# Cf graphical analysis

In this repository is designed the variation of the expansion efficiency factor (C_f) through a convergent-divergent nozzle of an ideal Liquid Propellant Engine that is using LOX and RP-1 as the propellant. All the variables are taken considering 1.013 bar as the external pressure (constant for this application) and 21.5 bar as the chamber pressure (constant as well). I considered also 0.96 as a standard parameter of the efficiency of the entire expansion.

## What the graph shows us
- **Language:** MATLAB
- **The aim:** [Is shown the nozzle length value for an adapted nozzle, avoiding the values that can bring to an over or under expanded nozzle. In this case we can get it just knowing the area ratio value for the highest Cf value.]
